# CS109 Project
基于Java语言的中国象棋游戏

### 任务1：游戏初始化
- [ ] 正确开始游戏
- [ ] 正确绘制棋盘，包括界河、九宫、初始棋子
- [ ] 正确显示游戏状态，初始状态是棋子在起点
- [ ] 可重新开始游戏（非重新运行代码）
- [ ] 正确显示当前玩家
- [ ] 游戏运行顺畅

### 任务2：多用户登陆
- [ ] 正确的用户登陆界面，和用户密码验证
- [ ] 游客模式无需登陆，无法存档
- [ ] 用户注册功能（用户名已存在则不可注册）
- [ ] 程序退出后，下一次运行依然可以登陆

### 任务3：存读档
- [ ] 登陆用户实现存读档
- [ ] 用户存档可以覆盖之前的存档
- [ ] 存档需包含棋子位置、谁的回合等信息
- [ ] 检查存档是否被人为破坏（内容或格式错误等），如有异常程序不报错或崩溃
- [ ] 用户只能读取自己的存档

### 任务4：游戏运行
- [ ] 玩家按正确的顺序轮流下棋
- [ ] 棋子只能按照合法的规则移动
- [ ] 正确实现吃子、将军、头像等功能
- [ ] 正确显示吃子、将军、认输、和棋等状态
- [ ] 状态能显示对方上一步移动的棋子和移动位置
- [ ] 游戏结束后，可重开游戏

### 任务5：图形化界面
- [ ] 图形化界面显示游戏
- [ ] 用户可以通过点击棋子进行棋子的移动
- [ ] 游戏过程中不需要与commandline进行交互
- [ ] 图形化界面游戏显示无异常
